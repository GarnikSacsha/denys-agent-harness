# Prepare a handoff

1. Use `.harness/templates/HANDOFF.md` as the structure.
2. Include repository, worktree, branch, Git state, runtime, ports, and deployed version when applicable.
3. Record accepted, rejected, and open decisions.
4. List changed files and exact checks with results.
5. Name risks, unknowns, files not to touch, and the exact next step.
6. Make the output copy-paste-ready and factual; do not rely on hidden conversation context.
