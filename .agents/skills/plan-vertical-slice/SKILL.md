# Plan a vertical slice

1. Define the user-visible outcome and one real scenario.
2. Inspect the existing implementation and constraints.
3. Specify states, data, errors, in-scope, out-of-scope, and acceptance criteria.
4. Select the smallest implementation consistent with current architecture.
5. Separate decisions requiring Denys from reversible engineering choices.
6. Define verification before code changes.
7. Produce a copy-paste-ready task contract.
