# Orient project

1. Read the applicable Harness and closest project instructions.
2. Resolve the real repository root, worktree, branch, and uncommitted changes.
3. Identify entry points, runtime, persistence, integrations, tests, and verified commands.
4. Compare current documents with code and observable behavior.
5. Report the user-visible product path, architecture, proven facts, risks, and smallest useful next vertical slice.
6. Do not modify files.
